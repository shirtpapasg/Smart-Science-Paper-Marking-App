The big idea
  1. A shadow changes size when the distance between the light and the object changes.
  2. Light closer to the object: bigger shadow. Further away: smaller.
  3. A shadow also changes size when the distance between the object and the screen changes.
  4. Screen closer to the object: smaller shadow. Further away: bigger.
