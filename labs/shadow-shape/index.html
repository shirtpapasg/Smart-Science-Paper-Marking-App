The big idea
  1. One object can make shadows of different shapes.
  2. The shadow's shape depends on which part of the object is blocking the light.
  3. Turn the object and a different part faces the light, so the shadow changes.
  4. An object that looks the same from every side, like a ball, makes the same shadow every time.
